Taska is a web application that provides a personalized dashboard for managers and employees, based on a feature flag system depending on the user's role.

## ✨ Features

### Authentication
- Email/password login with JWT token management
- Role-based access control

### Dynamic Dashboard
- Personalized dashboard based on user role
- Feature flag system with auto-configured UI
- Color-coded cards by feature type

### Feature Flag System

Features are dynamically loaded based on user permissions. 
Card configuration in `card-config.ts`:

``` typescript
export const CARDS: Record<string, FeatureData> = {
  "planning": {color: "sky", icon: "calendar_month", title: "Planning", details: "Aujourd'hui"},
  "active-employees": {color: "sky", icon: "productivity", title: "Membres actifs", details: "Aujourd'hui"},
  // ...
}
```
Then, the features are automatically loaded in the dashboard when the feature key with their data are received.

## 🛠️ Tech Stack
- NestJS
- TypeScript
- Mongoose
- Passport.js
- Apollo
- GraphQL

## 🏗️ Architecture
- **Authentication**: Local then JWT with Passport.js
- **GraphQL API**: Apollo Server
- **Database**: MongoDB with Mongoose
- **Feature Flags**: Role-based access

## 📋 Prerequisites
- Node.js (version 22.20.0 or higher)
- Nest CLI (version 11.0.16 or higher)

## 🔧 Installation
Clone the repository, then type in the command line : ```npm i```

- Run in development: ```npm run start:dev```
- Build: ```npm run build```

The API will be available at ```http://localhost:3000```.

## 🚀 Environment Configuration

Create a file ```.env``` :

```
CLIENT_SECRET='<JWT_CLIENT_SECRET>'
CLIENT_PATH='<CLIENT_URL_PRODUCTION>'
BACK_PATH='<BACKEND_URL_PRODUCTION>'
LOCAL_CLIENT='<CLIENT_LOCAL_URL>'
BDD_PATH='<MONGODB_CONNECTION_URL>'
PORT=3000
```

There are multiple entities : 
- User :
  - id: string (generated by mongo)
  - email: string
  - password: string (hashed with bcrypt)

- Profile :
  - id: string (generated by mongo)
  - firstName: string
  - lastName: string
  - birthDay: string
  - city: string
  - tel: string
  - role: string
  - userId: string

- Feature :
  - id: string (generated by mongo)
  - key: string
  - description: string
  - enabled: boolean

- FeatureAccess : 
  - id: string (generated by mongo)
  - featureId: string
  - role: string

- ProfileFeatureData : 
  - id (generated by mongo)
  - profileId: string
  - featureId: string
  - data: string[]

## 📚 API Documentation
GraphQL Playground available at: `http://localhost:3000/graphql`

GetProfile Example : 
``` graphQL
query GetProfile($userId: String!) {
  getProfile(userId: $userId) {
    id,
    role,
    firstName,
    lastName,
    city,
    birthDay,
    tel
    features {
      featureKey,
      data,
      genericData
    }
  }
}
`;
```
